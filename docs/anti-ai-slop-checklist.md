# Anti AI-slop checklist

Use this before merging UI work.

- Does every visual element have a job?
- Is there one obvious primary action?
- Are there fewer than three accent colours on a screen?
- Would the layout still make sense with all shadows removed?
- Are rounded rectangles used only when the shape communicates a control/state?
- Are emoji avoided for primary navigation and serious actions?
- Is copy specific to learning Japanese rather than generic motivational filler?
- Are decorative Japanese motifs restrained and semantically harmless?
- Does the mobile layout keep the flashcard/action area above the fold where practical?
- Are loading, focus, keyboard, reduced-motion, and empty states treated deliberately?
