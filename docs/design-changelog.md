# Design changelog

- Reframed the home screen as a study workspace, not a dashboard.
- Replaced generic hero/chips/action cards with an editorial hierarchy.
- Reduced visual palette to paper, ink, muted grey, and vermillion.
- Removed decorative background blobs and rounded-card styling in the override layer.
- Restyled flashcards, progress, ratings, filters, and bottom navigation with square geometry and lighter motion.
- Added reduced-motion support and explicit focus-visible styling.
