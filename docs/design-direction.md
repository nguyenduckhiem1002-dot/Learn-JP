# Learn-JP visual direction

## Goal
Create a Japanese study interface that feels authored, calm, and useful rather than template-generated.

## Principles
- Editorial hierarchy over dashboard chrome.
- One accent colour (vermillion) plus ink/paper neutrals.
- Square edges and visible rules instead of rounded cards everywhere.
- No glassmorphism, neon gradients, floating blobs, giant emoji, or decorative KPI cards.
- Motion only communicates state changes.
- Japanese identity comes from typography, spacing, furigana, and a restrained seal mark — not themed clip-art.
- Study actions are ordered by learning value, not gamification intensity.
- Dense enough to feel like a study tool; generous enough to stay readable on mobile.

## Home screen hierarchy
1. Product identity / learning statement.
2. Today's workload.
3. Primary study action.
4. Secondary test modes.
5. Bottom utility navigation.

## Study screen
The flashcard remains the dominant object. Rating controls sit below it and use a neutral system with semantic state colours only where needed.
